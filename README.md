# tariffpeg

Guest review evidence pipeline for an accommodation standards unit.

The unit licenses serviced accommodation and each licence carries a schedule of
particulars: the claims the operator registered when they applied. Guests write
about those same things on booking channels. `tariffpeg` harvests that writing
under a documented fetch policy, turns it into assertions about the particulars,
and decides which licences need an inspector sent out.

Early days. The CLI is not wired up yet.
