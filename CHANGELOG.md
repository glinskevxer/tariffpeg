# Changelog

## 1.0.0

The version the unit runs on. Everything below was in 0.1.0 and still is.

- Publishes rule pack two, twelve rules wider than pack one, and keeps pack one
  readable so a case file that cited it can still be answered in its own terms.
- Minutes a month of decisions into a ledger, and sets that ledger against what
  the evidence says today so a licence that moved after the operator was written
  to is visible.
- Drafts the letter a case file produces, and chases it twice before the unit
  stops writing and sends somebody instead.
- Works out what a harvest will cost each channel before it starts, and shortens
  the plan to what the day allows rather than stopping halfway through.
- Shows what a month of visits does to each inspector's diary, and says when a
  run filled one week and left another inspector with nothing.
- Never drops the page a minuted decision was taken on.
- Answers `db health` with one reading the overnight job can act on.
- Takes a consistent copy of the store while it is open, and compacts it.
- Reads the days the authority is shut out of the settings, so a reply deadline
  and a visit both skip them.

## 0.1.0

The first version that does the whole job.

- Reads a channel under a written fetch policy, obeying its robots file, a
  crawl delay, a courtesy window and a daily ceiling.
- Extracts reviews with a profile written in a file rather than in code, and
  says when a profile has stopped working instead of reporting no reviews.
- Redacts personal data on the way in, and keeps the digest of the bytes that
  were served so any quotation can be answered for.
- Recognises a syndicated copy of a review so one guest counts once.
- Sets what a guest said against the particulars on the licence, weighs it by
  kind and age, and corroborates it across independent channels.
- Holds a disposition at a desk enquiry while the statutory sample is short.
- Discounts evidence an accepted remediation notice has answered.
- Books a visit on a day the premises is open and an inspector is free.
